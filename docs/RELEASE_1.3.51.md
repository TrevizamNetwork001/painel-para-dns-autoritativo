# Release 1.3.51 — Serial mismatch com estado semântico

- Zero divergências exibe SVG de sucesso, linha verde e “Sem serial mismatch”.
- Uma ou mais divergências mantêm SVG e cores de alerta.
- O estado visual acompanha automaticamente a observação autoritativa.
- O rodapé do dashboard exibe automaticamente a release implantada na imagem.
- Transferências, zonas expiradas e publicações pendentes usam sucesso verde quando estão zeradas e alerta quando exigem ação.
