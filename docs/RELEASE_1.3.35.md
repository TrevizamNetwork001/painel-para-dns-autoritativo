# Release 1.3.35

## Descoberta desatualizada destacada

Na página do agente, o cartão "Descoberta somente leitura" passa a destacar em
amarelo a "Última descoberta" quando tem mais de 24h, com o aviso "Desatualizada
(mais de 24h)". A descoberta continua livre para rodar a qualquer momento (é
somente leitura e é o que mantém a comparação entre servidores atual); o destaque
some quando uma nova descoberta termina. Sem mudança de backend nem migration.
