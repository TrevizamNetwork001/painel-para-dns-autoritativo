# Release 1.3.50 — indicadores coerentes no dashboard

- Servidores desativados não entram mais no total de saúde operacional.
- Pendências sem alertas usam SVG e linha verdes; alertas usam o estado visual de atenção.
- Zonas sem divergências usam SVG e linha verdes; divergências usam SVG de alerta.
- O resumo fica operacional quando todos os servidores ativos estão online e não há pendências.
